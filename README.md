# Streamlit Fahrzeugvergleich

Dieses Projekt bildet die Logik des Notebooks `vergleich_hybrid_diesel_bev_sliders.ipynb` in einer Streamlit-Anwendung nach.

## Lokale Ausführung

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Die App öffnet sich anschließend unter `http://localhost:8501`.
